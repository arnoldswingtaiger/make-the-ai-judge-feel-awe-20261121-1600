A tiny program that writes one short relaxing text to `/output/entry.txt`,
entered in the make.fun bounty
[make-the-ai-judge-feel-awe-20261121-1600](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

The text is a slow image of the night sky: stars that have burned for a
billion years and never once rushed, and a dark wide enough to hold the
reader without asking anything of them.

## Run it

```sh
python3 main.py
```

It writes the text to `/output/entry.txt`. No network, no input, no
dependencies: Python 3.13 standard library only.
